# YingK

基于 Typecho 的简约博客主题，单栏、纯文字阅读导向。

本项目基于 [heysiu/Ying](https://github.com/heysiu/Ying) 二次开发，原主题更名为 **YingK** 并持续维护。

## 环境要求

- Typecho 1.2.1 及以上（基于 1.3.0 适配验证）
- PHP 8.x

## 功能特性

- **夜间 / 白天模式**：右下角悬浮按钮切换，跟随系统偏好，localStorage 记忆，0.35s 过渡
- **AJAX 局部加载**：站内跳转时页头不动，仅替换内容并淡入；支持前进/后退，异常自动回退整页
- **动态友链**：后台可视化增删友链（头像 URL + 名字 + 链接 + 简介），可整体隐藏
- **联系方式管理**：预设类型下拉（GitHub/邮箱/微博/X/B站/知乎/Telegram/自定义）动态增删，显示在头像行右侧
- **一言**：固定内容或接入一言 API（可选分类、可开关出处），加载防闪烁
- **文章页**：中文日期、浏览计数（同 IP 同日去重）、字数统计、代码块语法高亮（VS Code Dark+ 配色）与一键复制
- **悬浮按钮**：文章页回到顶部 / 直达底部（滚动位置自适应显隐）
- **后台可调**：卡片透明度（自由数值）、背景图、页脚版权（{Y} 占位符）、ICP / 公安备案号
- 归档模板（按月分组）、独立关于页样式、404 页
- 零第三方运行时依赖：图标 RemixIcon、语法高亮 highlight.js 均本地自托管

## 使用方法

1. 将本主题文件夹放入 Typecho 的 `usr/themes/` 目录
2. 后台「控制台 → 外观」启用主题
3. 后台「控制台 → 外观 → 设置外观」配置头像、一言、背景图、联系方式、友链等
4. 如需归档页 / 友链页：新建独立页面，"自定义模板"分别选择「归档」或「友链」
