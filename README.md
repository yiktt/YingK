# Ying 颖

Typecho 简约博客主题 —— 单栏、纯文字阅读导向，支持夜间模式。

原作：颖宝（v1.0，已停更），本版本为其适配 Typecho 1.2+ 的现代化维护版。

## 环境要求

- Typecho 1.2.1 及以上（基于 1.3.0 适配验证）
- PHP 8.x（需 pdo_sqlite / mbstring 等 Typecho 常规扩展）

## 主题特性

- **夜间 / 白天模式切换**：右下角悬浮按钮一键切换，跟随系统偏好，localStorage 记忆选择，切换带平滑过渡动画
- 单栏极简布局，首页为"日期 + 标题"式随笔列表，日期为中文格式（2026年10月24日）
- **全站背景图**：柔和渐变背景 + 毛玻璃半透明卡片，后台"背景图"选项可自定义更换
- **全站页面过渡动画**：进入任何页面（包括未来新增的页面模板）时卡片淡入上浮
- **右下角悬浮按钮组**：搜索（弹出式输入框，回车跳转搜索页）、主题切换，文章页另有"回到顶部 / 直达底部"
- **文章页元信息**：日期、作者、分类、浏览次数（自动计数）、文字数量
- **归档模板**：按月分组、篇数徽章、整齐的日期+标题条目列表（`articles.php`，建页面时选"归档"模板）
- 图标库 RemixIcon 4.9.1 与鸿蒙字体全部本地自托管，无外部 CDN 依赖
- 零第三方 JS 依赖，全部原生实现
- 后台可配置：头像、一言、背景图、备案号
- 不带评论系统（极简设计取向，如需评论可自行接入静态评论系统）

## 使用方法

1. 将 `Ying` 文件夹放入 Typecho 的 `usr/themes/` 目录
2. 后台「控制台 → 外观」启用本主题
3. 后台「控制台 → 外观 → 设置外观」填写头像、一言、背景图等配置
4. 如需归档页：新建独立页面，右侧"自定义模板"选择「归档」

- **无障碍**：悬浮按钮/工具坞/搜索框/复制按钮增加 `:focus-visible` 键盘焦点环
- 移动端走查确认：390px 视口无横向滚动、代码块横向滚动兜底、工具坞/返回钮正常
