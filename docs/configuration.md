## 独立页面

在「管理 → 独立页面 → 新增页面」创建页面，并在右侧「自定义模板」中选择对应模板：

| 页面 | 模板文件 | 说明 |
| --- | --- | --- |
| 归档 | `articles.php` | 按年月分组列出全部已发布文章，自动排除定时发布文章 |
| 友链 | `links.php` | 读取外观设置中的友链数据；页面正文不渲染 |
| 关于 | `about.php` | 站点档案·摘录笺；六字段结构化内容 + 自定义内容板块 + 可选统计卡；正文仅在外观设置中维护，独立页面正文不参与渲染，顶部不显示站长 / 主题 / 程序名片 |
| 普通页面 | 默认模板 | 仅显示标题与正文 |

- 旧版 `start-page` slug 页面仍会被识别为关于页，渲染同样的标题、统计与结尾「完」；页面正文同样不参与渲染，新站点建议直接使用 `about.php` 模板。
- 友链页可在外观设置中整体隐藏；隐藏后导航不再显示友链入口。
- 归档页、友链页与关于页的页面正文不会被输出，适合只作为功能页使用。

置顶文章只作用于首页第一页，按后台填写顺序显示；左侧用连续朱砂竖线串联，并在第一篇日期旁显示「置顶」小印。只接受已发布、未加密的文章，删除、草稿、定时或加锁文章会被跳过；置顶文章会从首页普通列表移除。

关于页的导语、关于主题、结尾寄语和自定义板块正文支持 Markdown；引言、内容方向和技术栈按结构化纯文本输出。Markdown 中的原始 HTML 会被转义，不会直接执行。关于页正文完全来自外观设置，独立页面编辑器里的正文不参与渲染、可留空。内容方向与技术栈的分隔符可用英文 `|` 或全角 `｜`。关于页、归档页、友链页等自定义模板被设为密码保护时，只显示核心解锁表单，不输出结构化正文、统计或列表；解锁后恢复正常内容。

站点档案采用「摘录笺」内容板块：导语、引文（朱砂竖线题记）、内容方向、关于主题、技术栈以及可新增的自定义板块依次排成单栏页边摘录，末尾接站点足迹与近一年热力图。窄屏下页边标签收进正文上方，技术栈改为标签/值清单；时间线/热力图使用已发布文章的创建/修改时间，不读取 IP 或评论，锁定文章标题只显示“此内容被密码保护”。时间线和热力图共享轻量签名缓存，文章发布/删除/编辑、建站日期/时区变化以及文章加锁/解锁后失效。数据缓存放在 PHP 临时目录，不写入 Web 根；缓存不可写时回退实时计算。

联系方式和友链以 JSON 保存，后台提供增删编辑，保存时会校验格式；根节点必须是列表（数组），不接受对象形态。联系方式每项的 `type` 必须在类型白名单内，`type`/`url`/`icon` 必须是字符串；友链的 `name`/`url`/`desc`/`avatar` 也必须是字符串，避免异常数据导致前台错误。友链编辑器保留头像字段与预览（前台当前版式不显示头像，描述为空时右侧仍显示域名）。旧版固定字段会在首次打开设置或首次渲染时自动兼容读取。

### 联系方式图标

- 选择“自定义链接”类型时，会显示“图标”输入框；可填写图片 URL，留空使用默认链接图标。
- 图标地址只接受 `http://`、`https://` 或 `/` 开头的站内路径；不安全地址会被拒绝，渲染时也会回退到默认图标。
- 图标会从填写的地址加载。请确认该地址可公开访问、允许外链，并符合你的隐私预期。
- 其他预设联系方式（GitHub、邮箱、微博等）使用主题内置图标，不使用自定义图标。

## 字体

字体来源是互斥的单选，不是叠加优先级：

| 来源 | 行为 |
| --- | --- |
| ZQL CDN（默认） | 从 jsDelivr 加载仓库内置的 ZQL 子集，按字频分三片（`zql-c1/c2/c3.woff2`）并以 `unicode-range` 按需下载：常见页面首访通常只加载第一片，正文页多加载第二片，Fastly 兜底 |
| 本地字体 | 使用字体库中选中的文件；未选择时使用系统字体 |
| 系统字体 | 不输出 `@font-face`，不加载任何字体文件 |
| 鸿蒙 CDN | 从 jsDelivr 加载仓库内置的 HarmonyOS Sans SC Medium（`assets/fonts/harmonyos-sans-sc-medium.woff`），Fastly 兜底 |
| 自定义链接 | 使用“自定义字体地址”中的 URL |

### 上传与字体库

- 上传支持 `woff2` / `woff` / `ttf` / `otf`，按文件头识别格式，不依赖扩展名；同时校验容器长度、表数量与表目录边界，拒绝空壳、截断或只有 4 字节签名的文件，不会替换现有字体。
- 文件保存在 `usr/uploads/fonts/ying-font-<随机>.<格式>`，加入字体库并自动切换到本地字体、选中新文件。文件不写入主题目录，也不计入主题包体积。
- 再次上传同名文件会替换字体库中的旧条目，不会产生重复项。
- 字体库卡片可直接选择；删除是保存后生效。删除当前选中的字体会自动选择剩余字体；没有剩余则回退系统字体。
- 删除会同时删除上传目录中的文件；替换字体时，旧文件也会被清理。
- 单个文件上限取 PHP 的 `upload_max_filesize` 与 `post_max_size` 较小值，主题自身最高限制为 20MB。后台会显示当前服务器的实际上限。
- 新激活主题的默认来源是 ZQL CDN，字体文件随主题包分发（`assets/fonts/zql-c1/c2/c3.woff2`，合计约 1.26MB，分片按需加载，`@font-face` 见 `css/zql-fonts.css`）；换用本地字体后，这些文件仅占主题目录空间，不再被加载。
- 从旧版升级：已有 `fontUrl` 会作为“自定义链接”保留；旧的单字体设置会进入字体库并选中；两者都没有时沿用鸿蒙 CDN，避免旧站点外观突变。
- 后台上传的字体由站点管理员自行提供，不属于主题仓库。请确认字体授权允许你的站点使用；迁移站点时需一并备份 `usr/uploads/fonts`。
- 自定义字体地址只接受 `http://`、`https://` 或 `/` 开头；外部地址需支持 CORS，否则浏览器会拒绝加载并回退到系统字体。

## 一言

- 默认使用固定内容，且只显示句子；切换到 API 模式后才会请求一言接口。
- 分类参数会以多个 `c` 参数发送给 [hitokoto](https://developer.hitokoto.cn/)。
- 请求 3 秒超时；失败、超时或无内容时回退到固定内容，不会留下空白。
- 只有启用 API 模式时浏览器才会访问一言接口；固定内容模式不请求一言接口（字体等静态资源另计）。
- 移动端（宽度 ≤ 880px）一言换行独占一行并保持左对齐，字号略小（0.875rem）；联系方式贴页头最右，工具坞收成联系方式行末尾的汉堡菜单。工具坞收起或移动端未展开时，主题/搜索/RSS 不进入 Tab 顺序；跨 880px 断点会自动清理移动端定位。

## 浏览量

- 计数保存在文章的 `views` 自定义字段，后台文章编辑页可以看到该字段。
- 同一浏览器对同一篇文章 **24 小时内只计一次**，使用 `ying_view_<cid>` Cookie 去重；不记录 IP，也不会在 `typecho_fields` 中写入每日去重标记。
- 清除 Cookie、换浏览器或使用无痕窗口会重新计数；爬虫与刷量不会被过滤，因此它表示“浏览热度”，不是独立访客数。
- 从旧版升级后，首次打开「设置外观」会清理旧版 `view_<md5>` 标记，不再污染后台自定义字段列表。

## AJAX 与渐进增强

主题会拦截同源站内链接与搜索表单提交，通过 `fetch` 替换内容区，页头、主题切换、搜索工具坞保持不变。以下情况会自动回退为整页跳转：

- 响应不是 2xx（包括 404）——锁定态文章的 403 例外：它是完整的主题页，会正常换入；
- 目标页面内容区包含 `<script>`（避免脚本不执行）；
- 页面结构不符合主题约定；
- 链接带 `download`、`target` 非 `_self`、跨域或指向后台；
- 链接显式添加了 `data-no-ajax`；
- 链接包含 `#锚点`：交给浏览器原生导航，跨页锚点不会在局部换页时丢失。

```html
<a href="/archives/42/" data-no-ajax>整页打开这篇</a>
```

换页后会恢复上一页的滚动位置、把焦点移到新页面 `h1`，并显示顶部细进度条。搜索提交以 POST 局部加载（跟随服务器重定向到 `/search/关键字/` 后替换内容区，地址栏为最终搜索页 URL）；后台表单与站外链接不参与局部加载。

搜索面板是独立于内容区的卡顶通栏：与内容卡同宽、从视口顶部翻落（翻盖动效，`prefers-reduced-motion: reduce` 下静止），打开即聚焦输入框，支持回车搜索、esc 或点空白收起，换页时自动关闭；按 esc 收起时，桌面把焦点还给搜索按钮，移动端还给汉堡按钮。宽度 ≤880px 时改为视口满宽（留 10px 边距），触屏不显示 esc 提示。移动端打开搜索会顺带收起汉堡菜单。

密码表单同样走局部加载：口令错误时返回的 403 锁定页会被就地替换，页头不动、地址栏不变，焦点落回密码输入框；口令正确时跟随重定向换入正文。从列表点开带锁文章时，403 锁定页同样就地换入，页头不会重刷。浏览器未执行脚本时自动回退为原生整页提交，功能不受影响。

## 部署安全提示

使用 SQLite 时数据库文件默认为 `usr/typecho.db`，位于 Web 根目录内，**必须禁止外部直接访问**（文件内含账号密码哈希、全部文章与站点设置）。实测在未加限制的服务器上 `GET /usr/typecho.db` 会直接下载整个数据库。

- Nginx：`location ~ ^/usr/.*\.(db|sqlite|bak)$ { deny all; }`（或对整个 `usr/` 目录 `deny all`，但需为 `usr/uploads/` 另开 `allow`，因为本地字体与上传文件要从这里加载）。
- Apache：在 `usr/` 下放置 `.htaccess`，内容 `Require all denied`（2.4）/ `Deny from all`（2.2）后，将 `usr/uploads/` 加入例外。
- MySQL 环境同样建议限制 `usr/backups` 等目录的访问。主题本身不读取也不依赖这些文件的可访问性。

其他与主题相关的安全约定：主题输出对标题、标签、分类、作者、一言、联系方式与友链均做 HTML 转义（`htmlspecialchars` + `ENT_QUOTES`）；`logoUrl`、`faviconUrl`、`bgUrl`、自定义字体地址走协议白名单（`http`/`https`/站内根路径），不安全地址会回落到内置资源；字体上传按文件头识别格式、限制 64MB，并拒绝任何不符合 `ying-font-<16位十六进制>.<woff2|woff|ttf|otf>` 命名的删除请求。正文字体之外的正文 HTML 由 Typecho 按作者输入原样输出（核心行为），多作者站点请自行限制作者权限或使用 HTML 过滤插件。

## 密码文章与错误页

- **密码文章锁定态**：文章设密码后，正文区替换为「编年 · 已加锁」小眉 + 编年空心节点 + 「密」印 + 下划线输入 + 「进入 →」文字钮（与 404 同一套设计）；**解锁前不输出文章标题、日期、作者、分类、浏览等元信息，也不输出标签/摘要的 meta keywords/description/social**，只保留页面标题（沿用核心的「此内容被密码保护」占位）。关于、归档、友链等自定义模板被设密码时同样只输出核心解锁表单，不显示结构化正文、统计或列表。
- **口令校验与错误提示**：口令错误不再跳到独立报错页，而是停在本页（局部加载，页头与地址栏不动），在输入框下显示一行朱砂小字「口令不符，请重试」，密印轻震两下，其余内容不重放入场动画（只有印章在动；`prefers-reduced-motion: reduce` 下自动静止）。校验通过后写入与核心同名的解锁 cookie 并回跳本页，之后刷新仍保持解锁；令牌校验以固定文章地址为盐（`yingLockToken`），提交缺少有效令牌时回到固定文章地址，不跟随外部 Referer。
- **错误页接管（可选）**：Typecho 核心异常（如核心直接抛出的 403、数据库 503）默认使用内置极简页。要在主题版式中显示，在站点根目录 `config.inc.php` 中加一行（路径按你的主题目录名调整）：

```php
define('__TYPECHO_EXCEPTION_FILE__', __DIR__ . '/usr/themes/Ying/error.php');
```

  启用后：403 显示「编年 · 口令不符 + 403 + 封印」，其他 5xx 显示「编年 · 出错」变体；错误文案取自核心，支持「再试一次（返回上一页）」与「返回首页」。不启用时主题其余功能不受影响。
